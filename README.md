# Field Assistant — Treatment Toolkit

A free, offline-capable water-treatment field-dosing web app. Open it on your phone,
**Add to Home Screen**, and it runs like a native app with no signal.

**App:** https://uqh108-max.github.io/field-assistant-toolkit/

Everything you save (clients, pumps, products, jar tests) stays **on your device** in the
browser; nothing is uploaded. Use **Clients → Backup & restore** to keep a copy off the phone.

This repository only hosts the published app files. Doses and specifications are indicative
and must be confirmed against the current supplier data sheet and site conditions (jar/plant
trials). No warranty is given.
